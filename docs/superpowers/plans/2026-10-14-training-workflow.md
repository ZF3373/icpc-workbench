# 训练闭环优化实施计划

**目标：** 在今日训练完成查看任务、选择账号同步、确认 AC 打卡，并提供计划批量调整与 AI 降级说明。

**实现：** 复用现有路由和数据表；新增小型任务查询与重排服务；不修改已有提交、复习调度与能力估算口径。

**约束：** 自动识别仅针对当天练习任务，必须当日有 AC 证据，用户确认后打卡；多账号逐个同步、逐个反馈；重排保留任务 ID 和已打卡任务，固定比赛及复习任务不自动改期；不增加依赖。

1. [x] 补充失败测试：今日任务字段、当日 AC 识别与确认、重排保留打卡及唯一约束、降级原因、多账号目标筛选。
2. [x] 实现共享任务查询 `server/src/plans/todayTasks.ts`；`GET /api/today` 返回 `planTasks`，`POST /api/checkins/auto-today` 预览或确认。
3. [x] 新建 `server/src/plans/reschedule.ts`；`POST /api/plans/:id/shift` 支持 0–30 天顺延、避开周末、每日 1–6 个可调整任务上限，事务更新并扩展周期。
4. [x] `generatePlan` 返回分类后的安全降级原因，生成界面保留告警并支持按原参数重试；复用现有 provider 注入支持无网络测试。
5. [x] 今日页面展示当天任务、分组与打卡；新增账号选择及逐账号同步；同步后预览已 AC 任务，用户确认后打卡。
6. [x] 计划详情提供批量调整面板和确认说明；完善 README。
7. [x] 运行新增回归测试、完整测试、类型检查、前端构建和差异检查，复核任务范围与日期边界。
