# WebDAV 双向增量同步

## 使用方法

1. 打开「设置 → 数据管理 → WebDAV 数据同步」，填写已有的 WebDAV 目录地址、账号和密码或应用密码。
2. 点击「测试连接」，再保存设置。点击「立即同步」可手动同步，也可开启自动同步，在应用运行期间定期检查。默认每 5 分钟检查一次，可设为 1 至 1440 分钟。
3. 在其他设备上使用相同的 WebDAV 目录。首次连接已有数据的目录时，如果两端内容不同，应用会提示选择保留本地或 WebDAV 的版本。

## 同步范围和冲突处理

- 同步平台账号绑定、提交记录、训练计划、打卡、复习记录、题库、题单、模板、比赛记录、笔记引用的上传图片及知识点标注。登录凭据、应用密钥、设备设置与浏览器本地数据留在原设备。
- 只有一端发生变化时，应用自动上传或下载。两端分别发生变化时暂停，等待用户选择保留的版本。如果确认后数据又发生变化，应用会要求重新选择。
- 下载的数据会校验哈希。数据库写入使用事务并检查外键，本地在下载期间有新编辑时会保留编辑。应用远端数据前自动创建本地恢复点，可在「备份与恢复点」中找到「WebDAV 同步前」记录。

## 服务端要求

- 应用在填写的目录下创建 `icpc-workbench-sync-v1/`，其中存放同步清单和按 SHA-256 标识的数据块。已有相同内容的块会复用。修改一条记录通常只影响包含该记录的数据块。
- WebDAV 端点需支持 `PROPFIND`、`MKCOL`、`GET` 和 `PUT`，并提供强 ETag 与条件写入。填写最终目录地址，外网访问使用 HTTPS。配置支持匿名和 Basic 身份验证。
- 各设备应使用兼容的数据表版本。单份同步数据上限为 256 MiB。远端会保留此前上传的数据块。

## 验证

- 覆盖首次同步、双向增量、删除传播、连接配置、冲突处理、外键回滚和标注恢复。
- 使用两个独立数据库和本地 WsgiDAV 验证上传与下载。修改一条训练计划时，每个方向各传输一个数据块。
- 开发和桌面入口挂载相同的 `/api/webdav-sync` 路由。Windows 便携测试包通过打包后启动检查。
