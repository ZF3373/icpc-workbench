# 复习库笔记全屏阅读（issue #52）

针对「复习库笔记查看时太小了，查看复习不方便，希望增加放大全屏功能」，在已有的「宽卡片 + 卡内字号缩放」之上补了**全屏沉浸阅读**（issue 回复里选定的方案 B：隐藏标题栏 / 工具栏，只留正文，Esc 退出）。

## 新增

### 笔记全屏沉浸阅读

笔记卡片标题栏新增「全屏」按钮，点击后卡片铺满整个应用窗口：

- **去掉标题栏、meta 与编辑入口**，只剩正文和右上角一个「退出全屏 Esc」按钮。
- **正文吃满剩余高度**，不再受卡片态 `min(62vh, 640px)` 的限制；行长收在 980px，宽屏读长笔记不会一行上百字。
- **Esc 分两层**：全屏时第一下只退出全屏（读者还在读，不该一下把卡片也关掉），回到卡片态再按一次才关闭卡片。全屏态的 X 与 antd 的 Esc 关闭都被关掉，避免「一退全屏就顺带关卡片」。
- **Ctrl + 滚轮 / 卡内缩放照旧生效**，与卡片态共用同一个「笔记文字」比例（50%–200%，独立持久化）；退出的按钮不跟着变大。
- 复习库 / 模板库学习笔记 / 训练计划·日历·今日训练的任务备注**三处入口同一套行为**。

无障碍与细节：

- 全屏态保留一行纯文本标题作为无障碍名称（rc-dialog 的 `aria-labelledby` 指向它），视觉上整条隐藏；用 clip 而非 `display:none`，否则会脱离无障碍树。
- 进入全屏焦点落到「退出全屏」，退出全屏焦点还给「全屏」按钮；切换形态时正文滚回顶部。
- 卡片头为 antd 的关闭 X 预留了位置：工具组变宽后不再压住 X（实测原先重叠 19–27px）。
- 窄屏（≤640px）下「全屏」按钮只留图标，标题仍能露出一截。

## 验证与打包

- `npm run typecheck`
- `npm run lint`
- `npm run check:tokens -w client`
- `npm test`
- 本地结果：前端 635 项测试通过（新增 `noteCardWidth` 单测），类型检查、lint（0 error）、对比度、16 组主题 Token 配对、过渡时长门禁全部通过。
- 真实浏览器（headless Chrome + CDP）实测：1440 / 1280 / 900 / 768 / 640 / 480 六个宽度，亮暗两套主题；全屏容器精确铺满视口（0 溢出）、退出栏与正文不再横向并排、Esc 两次分别退出全屏与关闭卡片、关闭 X 在所有宽度下均未被遮挡；`--app-zoom` 125% 下全屏宽度仍等于视口宽（不溢出）。
