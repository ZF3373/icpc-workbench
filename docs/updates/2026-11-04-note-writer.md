# 复习库笔记写作（issue #52 后续反馈）

issue #52 最新回复：「笔记查看卡片 + 字号缩放 + 全屏沉浸阅读，这个体验非常好，但是**复习库的复习笔记编辑编写时貌似还没有相关功能，只能扩大查看**，希望可以同步一下阅读卡片、全屏三栏写作与视图持久化，类似的功能。」

也就是把模板库那套写作体验（`602484f` 的「阅读卡片、全屏三栏写作与视图持久化」）复刻到复习库的笔记编辑上。

## 新增

### 统一的笔记写作弹窗 `NoteWriterModal`

复习库与模板库的学习笔记改用同一个写作弹窗，两种形态：

- **卡片态（默认）**：760px 定宽，正文吃满一屏（420px），页脚常驻「全屏写作 / 字数 / 取消 / 保存」。
- **全屏三栏（沉浸写作）**：铺满整个应用窗口，隐藏标题栏，三栏从左到右依次是 ——
  - 01 实时预览：跟随改动渲染（GFM 表格、KaTeX、代码卡）；
  - 02 写作上下文：复习库放**复习节奏**（下次到期、上次复习、间隔档位、标签与「先写关键观察 / 再写易错点」的提示），模板库放**模板大纲要点**；
  - 03 MD 写作：**写作区放在最右侧**（右手边写、左边看渲染结果更顺手），完整 Markdown 工具栏 + 代码高亮，撑满整栏，并给到最宽的一列（0.95 : 1.25 的旧比例改为 1 : 0.9 : 1.25）。
- **Esc 分两层**：全屏时第一下只退全屏，回到卡片态再按才关弹窗；全屏态的 X 与 antd 的 Esc 关闭都被关掉，避免「一退全屏就顺带把草稿丢掉」。
- **「笔记文字」缩放照旧**：全屏顶栏与卡片工具栏共用同一个 50%–200% 比例，Ctrl+滚轮在正文 / 预览上生效，按钮与标题不参与缩放。

### 视图持久化 `noteWriterView.ts`

- 记住上次是不是**全屏写作**、以及卡片态停在**编辑 / 分栏 / 预览**哪一档（`icpc-note-writer-view-v1`）。
- 读取时做结构归一化：非对象、`"false"` 这种手改字符串、未知模式一律丢弃回落默认值（与 `templateView.ts` 同一套口径），并有单测锁住。
- 全屏宽度取 `--app-viewport-width` 而不是 `100vw`：整页缩放（`--app-zoom`）后 `100vw` 会横向溢出。

### 窄屏与可达性

- ≤640px 时卡片态不再提供「分栏」：760px 弹窗里两栏各只有 ~190px，编辑器和预览都读不了；改成「编辑 / 预览」二选一（由 JS 断点换模式集合，纯 CSS 做不到）。
- 全屏三栏在 ≤920px 收成单列纵向堆叠，每栏限高、各自可滚；**堆叠后写作区用 `order: -1` 排到最前**（先落到能打字的地方），此时 01/02/03 编号会误导，单列下不显示编号。
- 进入全屏焦点落到「退出全屏」，退出全屏（按钮或 Esc）后焦点回到「全屏写作」，不会掉到 body；全屏态保留一行视觉隐藏的纯文本标题作为无障碍名称（rc-dialog 的 `aria-labelledby` 指向它）。
- 保存中按钮进 loading，取消 / 关闭都被挡住，避免半截内容落盘或重复提交。
