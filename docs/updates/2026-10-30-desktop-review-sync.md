# 桌面体验、复习入口与牛客 / VJudge 同步更新

本次更新针对链接添加复习题目、桌面关闭行为、掌握度地图跳转、外观背景和提交记录同步。以当前 master 为基础整合，保留已有设置拆分、主题 Token 配对和 DashOJ 等功能。蓝桥云课暂不包含在本次提交中。

## 修复

- **牛客账号标识不正确时同步失败**：牛客需要数字 UID，设置中支持直接填写数字 UID 或个人主页链接；昵称会返回明确的修改提示。
- **牛客记录来源不完整**：原适配器只读取 ACM 练习页。现在合并主站在线编程、ACM 练习和已参加竞赛的提交记录，仍使用同一个 `nowcoder` 平台。
- **牛客记录去重与续拉**：在线编程提交使用独立编号空间，ACM 练习 / 竞赛共享的提交编号去重；多个来源按页推进，一个来源结束不会让其它来源提前结束，条数上限中断后可从当前页继续。
- **牛客空记录误报与时间错误**：正常空表不再直接视为爬取失败；异常页面和接口失败明确报错。无法解析的提交时间不再伪装成当前时间；未完成评测的记录等待后续同步再导入。
- **掌握度地图题目点击无反应**：改为真实外链，AC / 未 AC 列表中的题目标题通过系统浏览器打开；无 URL 的条目仍禁用。
- **桌面关闭行为**：关闭主窗口隐藏到托盘，左键点击托盘或选择“打开算法工作台”恢复；“退出”才结束进程并关闭核心服务，辅助登录窗口保持正常关闭行为。

## 新增

### 通过 URL 加入复习库

复习库新增“通过链接添加”入口和 `POST /api/reviews/from-url`。使用已有题目链接解析规则识别支持平台，可选填写标题。不抓取任意外部网页，也不生成虚假的提交或 AC 记录。重复添加保留原有题目信息、复习阶段和到期日期；首次加入使用既有排期规则。

新增牛客主站 `/practice/{uuid}` 链接识别，与在线编程同步使用相同题目键。VJudge 转发链接仍沿用已有的原 OJ 映射规则，不表示支持任意 OJ 的题面导入。

### VJudge 提交记录同步

新增 `vjudge` 平台、用户名 / 主页链接绑定和公开提交列表适配器。支持分页、增量去重和分批续拉；按用户名核对记录归属。统一 AC、WA、TLE、MLE、RE、CE 判定，兼容大小写和 `on test N` 后缀；评测中 / 暂无最终判定的记录暂不入库。

VJudge 题目保留 `OJ-题号` 标识及 VJudge 跳转链接。本次没有添加 VJudge 全站题库、题名抓取或难度推测；可导入的记录范围取决于网站公开列表，私有和隐藏记录不保证可获取。

### Fantasy 风格与全局背景

调整深浅主题配色、侧栏、卡片、标题和按钮。颜色继续通过主分支的 `index.css` / `tokens.ts` 配对维护，保持 `check:tokens` 门禁。

设置页新增全局背景：本地图片、GIF 或视频；0–100% 显示强度实时预览并保存；重启保留；支持替换和恢复默认。媒体先检查能否解码再切换，失败保留旧背景。应用保存媒体副本，替换成功后仅清理旧的应用内副本。单文件最大 1 GiB，视频格式是否可用取决于浏览器 / WebView2 的编码支持。

视频静音循环播放；页面不可见或原生主窗口隐藏 / 最小化时暂停，恢复后继续。桌面壳新增窗口可见性命令。
